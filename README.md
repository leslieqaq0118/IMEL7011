# IMEL7011

English teaching materials for modeling and simulating a MEMS accelerometer.

## Materials

- [Classroom HTML](index.html): an interactive presentation with 17 topics. Download the file and open it in a browser. Images and simulation data are embedded, so it works offline.
- [PowerPoint](IMEL7011LabTutorial.pptx): 47 slides covering the design workflow, Simulink construction, results, AI-use requirements and optional bonus projects.

For the HTML presentation, use the arrow keys or Space to navigate, **F** for fullscreen, **N** for teaching notes, and **T** for the topic list.

## Experiment

The mechanical model maps casing acceleration to relative displacement. Two equivalent Simulink implementations use a transfer function and two integrators with feedback. The lesson includes step-response checks, damping comparisons, sine tests, and Bode magnitude and phase.

The demonstration uses assumed teaching parameters: mass 1 mg, undamped natural frequency 1000 Hz, and damping ratio 0.7. Students select and cite a consistent literature parameter set for their own experiment.

The course permits optional AI use with verification and disclosure in the report. Optional bonus projects follow the eligibility rules described in the teaching materials.
